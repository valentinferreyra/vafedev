# vafedev.me V1 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build the English V1 of `vafedev.me` with the approved Mineral Mist interface, repository-backed MDX content, connected professional sections, persistent theme selection, responsive navigation, and production discovery metadata.

**Architecture:** Keep public pages as App Router Server Components backed by a filesystem content repository. Isolate the small interactive surface—theme selection and mobile navigation—in Client Components, while shared page patterns render typed content and explicit related-entry references. Build-time validation makes malformed metadata, duplicate slugs, and broken relations fail before deployment.

**Tech Stack:** Next.js 16.3.6 App Router, React 19.2.8, TypeScript 5, Tailwind CSS 4, pnpm 11, MDX via `next-mdx-remote`, `gray-matter`, Zod, Vitest, Testing Library, and Playwright.

**Spec:** `docs/superpowers/specs/2026-09-30-vafedev-v1-design.md`

## Global Constraints

- Use the existing Next.js 16 App Router, React 19, TypeScript, Tailwind CSS 4, and pnpm scaffold.
- Read the relevant installed documentation in `node_modules/next/dist/docs/` before using Next.js APIs; do not rely on older conventions.
- All V1 interface and content copy is English; do not add language controls.
- IBM Plex Sans is the heading/body font and Geist Mono is the navigation/metadata font.
- Desktop sidebar width is 300px; mobile supports widths from 320px upward.
- Mineral Mist light is the initial theme only when no saved choice exists; a manual light or dark choice persists locally.
- Do not derive the initial theme from `prefers-color-scheme`.
- Content stays in repository MDX; do not add a database, remote CMS, comments, analytics dashboard, or advanced filters.
- Empty collections stay out of navigation.
- Do not invent biographical or employment claims. Initial prose and entries remain clearly generic placeholder content until Valentín supplies final copy.

## Review Focus

- Corrupt or unavailable `localStorage` must leave the page usable in light mode; Task 3 tests this fallback.
- A direct request for an unknown or draft slug must render not-found and never expose draft content; Task 5 tests both cases.
- A relation that targets a missing, draft, or wrong-collection entry must fail content validation; Task 2 tests all three inputs.
- Keyboard users must be able to open, traverse, and dismiss mobile navigation with focus restored to the trigger; Task 4 tests this behavior.
- An empty collection must disappear from navigation and sitemap while its direct collection route remains a valid, intentional empty state; Tasks 4, 5, and 7 test those outcomes.
